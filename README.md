# Auto Payload Parser

Payload verilerini tarayıcıda ayrıştıran basit bir araç.

JSON, query string, form, key/value, HTTP request ve JWT destekler. Serbest metinden IOC değerlerini ayıklar. Sonuçlarda arama, kopyalama ve CSV/JSON indirme yapılabilir.

`index.html` dosyasını açmanız yeterli. Bağımlılık veya backend yoktur. Veriler kaydedilmez, sunucuya gönderilmez. JWT imzası doğrulanmaz.

GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root) → Save**.

Test: `node tests.js`
